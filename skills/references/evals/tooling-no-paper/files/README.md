# benchmarks

Immutable benchmark datasets for the swarm-routing org: the raw marker lines of
every 20-seed run and the reproducibility manifest of each run. Runs are
produced with the `routing-bench` harness from swarm-routing/ns3-tools and the
AntHocNet protocol release (swarm-routing/AntHocNet).
